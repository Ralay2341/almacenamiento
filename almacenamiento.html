Asignación óptima de ubicaciones para pallets de ImportPropiedad de: Raúl Layseca Beas (Ley 17.336)

Parámetros de búsqueda

Si eliges un Código SAP, solo se calculan/asignan los pallets de Import con ese código. Si eliges un Rack destino, la búsqueda se limita SOLO a ese Rack (no expande a otros bloques). Si eliges un Tipo de Rack, solo se consideran ubicaciones de ESE tipo (SIMPLE/DOBLE/BAJO/PICKING/PILAR). Se completan al cargar los datos.

Ubicaciones vacías del Rack elegido

Útil cuando no hay ningún bloque con el código buscado: mostrá todas las ubicaciones vacías disponibles del Rack destino elegido arriba, respetando el Nivel inicio/final y el Tipo de Rack seleccionados (PILAR nunca aparece).
